# TechBazaar - User Flow & Project Plan

## User Flow

Home → Shop (Product Listing) → Product Details → Cart → Checkout → Order Success
              ↳ Wishlist (accessible from Navbar + Product Card)
              ↳ Recently Viewed (shown on Home + Product Details)

## Pages

- Home
- Shop / Product Listing
- Product Details
- Cart
- Checkout
- Order Success
- Wishlist

## Tech Stack

- Framework: React (via Vite)
- Styling: Tailwind CSS
- Data Source: DummyJSON Products API (https://dummyjson.com/docs/products)
- Cart Persistence: Local Storage
- Version Control: Git + GitHub
- Deployment (planned): Vercel or Netlify

## Store Concept

TechBazaar — an electronics-focused online store (smartphones, laptops, and
related accessories), sourced from DummyJSON's product categories.
